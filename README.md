# Jump to Ping

Jump to unread mentions, replies and DMs from a button beside the notifications bell.

- Tap the button for the list of chats with pings, tap a chat to jump to its first unread ping.
- Long-press the button to jump to the newest chat.
- Opened pings are not offered again, so the next tap goes to the next ping.
- Optional: replies without a ping, DMs, keeping pings until opened.
- Filters: ignore @everyone and @here, count all, all except or only chosen roles.

## Install

Add this URL in **Settings → Plugins → Settings Icon → Repository URL**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-Plugins/main/index.json
```

This repository holds the source and test builds of Jump to Ping. All plugins are published together in [dariussbezy's Plugins](https://github.com/dariussbezy/dariussbezy-Plugins).
